# Brew & Bean

A modern and responsive coffee shop website built using HTML, CSS, and JavaScript.

## Project Description

Brew & Bean is a modern coffee shop website with a warm and elegant design.
The website provides information about the coffee shop, its menu, customer reviews, and contact details.

## Features

- Responsive design
- Modern and clean UI
- Navigation bar
- Landing page
- About page
- Full menu page
- Menu categories
- Customer reviews
- Contact page
- Contact form
- Mobile responsive layout
- Smooth navigation between pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
